📔 일기장 연결

텔레그램으로 쓴 일기가 저장되는 GitHub 저장소를 읽어 옵니다. 토큰은 이 기기 브라우저에만 저장됩니다.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 일기 저장소 하나만 선택
  3. Permissions: Contents: Read and write (앱에서 쓰기·수정·삭제), Actions: Read and write (동기화·AI 분석)
